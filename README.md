# Task 14 - Loops and Number Operations

In this task I used JavaScript loops and conditional statements to perform different operations on a number entered by the user.

The program can:

* Find the sum of the first n numbers
* Print the multiplication table
* Check if the number is prime
* Find all factors
* Find the sum of digits
* Check if the number is an Armstrong number

One challenge I faced was understanding how the Armstrong number logic works. At first I only checked for 3-digit Armstrong numbers, but later I changed the code so that it works for numbers with any number of digits. I used the length of the number to determine the power for each digit.

I also added input validation to handle invalid input and negative numbers.

Through this assignment I practiced:

* for loops
* while loops
* if-else statements
* functions
* arrays
* user input using prompt()

This task helped me understand how loops can be used to solve different mathematical problems and how functions can make code easier to read and organize.
